# CampusFind Frontend

A complete React + Vite frontend prototype for a campus Lost & Found application.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, usually:

http://localhost:5173

## Notes

- This is frontend-only.
- Firebase is not connected.
- Featherless AI is not called from the browser.
- Mock data is stored in `src/data/mockData.js`.
- The UI is intentionally warm, humanistic and non-gradient.
- The app is structured so teammates can later replace mock data with Firebase/backend data.
